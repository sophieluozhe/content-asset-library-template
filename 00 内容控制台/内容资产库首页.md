# 内容资产库首页

## 工作流

输入资产 → 清洗与萃取 → 原子资产 → 主题 → 内容单 → 复盘回流

## 使用顺序

1. 原件只保存于 `01 输入资产/01 原始材料`，不覆盖、不删除。
2. 用清洗稿和萃取工作单记录加工过程，并保留来源锚点。
3. 将可复用内容沉淀为原子资产，再组合为主题和内容单。
4. 发布后记录复盘，并把新的线索回流为资产或输入。
